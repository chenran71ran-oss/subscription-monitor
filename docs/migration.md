# 从单文件版迁移

## Demo v18 → 开源 v01

首次开源版本统一为 v01，工具包版本 0.1.0，建议 Git 标签 v0.1.0。此前 Demo v18 只属于 Demo 开发阶段，不是第十八次开源发布。

控制中心当前版本、源码首行、README、变更记录和工具包版本已同步。旧版条目明确归为 Demo 开发历史，避免与新的 v01 混淆。生成文件已重新构建。

只有版本与历史说明文字调整，后端解析、API、KV 数据结构和既有界面布局不变。如果现有 Demo v18 正常运行，可以继续使用原部署；更新到 v01 不必重建 Worker 或更换 KV。

## 旧版升级

1. 受保护地备份旧源码和完整 KV；不要把备份提交 GitHub。
2. 对照新版本变更，保留 Worker 名称和 `SUB_KV` namespace ID。
3. 保留 ADMIN_TOKEN；旧 Windows 采集还需要 INGEST_TOKEN。
4. 完整部署生成的 worker.js，检查已有记录与文件来源。
5. 若格式未识别，提交最小脱敏样例；不要删除所有订阅来掩盖模板问题。

未提供任意历史版本 KV 的自动迁移承诺。当前数据沿用 list / data:<id> 结构；真实升级需保留旧版本与数据恢复途径。

## 客户端偏好

主题、卡片排序、折叠和显示模式在当前浏览器 localStorage。换域名 / 浏览器会获得新的偏好空间，KV 订阅记录不因此消失。管理口令也保存在浏览器中，注意受信任设备使用。

## 快照不是备份

控制中心导出的 JSON 不包含原订阅链接 / 节点 host / 密码，不用于恢复。KV 备份包含私密资源和地址，必须独立受保护保存。
