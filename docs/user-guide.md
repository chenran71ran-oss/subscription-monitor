# 使用指南

## 订阅状态

上方概览提供总体状态；下面订阅卡片使用一致的结构。字段未知时显示未知状态，不因某条订阅缺字段随意改变框体。

右上角从左到右是白天、跟随系统、黑夜、布局切换，末尾按钮可在同行收起工具。布局循环为详细、紧凑、磁贴、表格；当前偏好保存到此浏览器。底部三个入口为订阅状态、节点状态、控制中心。

桌面端增加信息空间，手机端压缩顶栏与地区占位。国旗 + 中文 + 英文来自节点名称推断；地区不是 IP 地理验证。台湾地区当前使用中国国旗，这是当前显示规则。

链接中的 `#` 参数在请求前移除；它们属于客户端配置，不是服务商配额。上传仅支持 UTF-8、非空、最大 1 MB 的节点配置文件。只有外部 `proxy-providers` 链接的配置不包含节点，请先下载对应节点文件。

重新导入使用原文件订阅 ID。无法解析到有效地址与端口的文件会拒绝覆盖，旧数据保留。这是数据导入保护，不能理解为在线源码更新保护。

## 看懂流量

“已用”和“剩余”来自上游可识别计数。总量和已用齐全时剩余为 `max(0, total - used)`；单独提供剩余时可显示剩余但总量仍未知。配额进度按消耗程度由绿色转向暖色 / 红色。

今日用量是配额快照差值，不是抓包统计。刚添加、午夜附近缺历史、上游计数重置或字段来源变化时可能不完整。界面保留今日，去掉本周用量。

详情中的手动流量校准适合填写服务商面板确认过的总量和剩余。它只是快照，不会依据 TCP 检测自动扣减，也不参与今日用量计算。后续有效自动配额可能覆盖该快照。

## 节点状态

点阵地球绕固定中心纵轴缓慢旋转，可水平拖动或用左右键旋转。地区数量按当前保留节点统计；不同订阅里的相同节点不自动去重。

协议分布和节点明细用于观察解析结果。TCP 可达不能证明代理密码正确；未检测、资源限制与 UDP 不支持不是明确离线。

## 控制中心与中控屏

- 状态快照：导出当前公共状态，不能恢复完整订阅。
- 采集记录：查看采集来源、时间与格式。
- 异常摘要：定位抓取、配额和探测问题。
- 版本记录：程序更新说明，不执行代码部署。
- 顶部中控按钮：打开集中展示，可切换浏览器全屏。

快照仍可能含订阅名称、节点名称与错误摘要，公开前必须人工检查。删除订阅会移除其列表记录和对应快照；布局与排序偏好保留在当前浏览器本地。

## 交互偏好

卡片拖动仅调整展示排序。主题、布局、部分折叠状态保存在 localStorage；不是多设备同步配置。液态动效直接嵌入按钮，无额外开关；遵循系统“减少动态效果”设置。不会有持续跟随鼠标的大光斑。
