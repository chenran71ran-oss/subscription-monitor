监控中控屏

节点只展示协议、状态与延迟，不含服务器地址和密码 · 延迟为 Cloudflare 机房到节点的 TCP 握手耗时，仅供判断连通性

访问面板

输入 Worker 中配置的 ADMIN_TOKEN。

添加订阅

由 Worker 定时访问订阅链接，适合大多数订阅。

请选择本地文件

支持 UTF-8 YAML / JSON / 节点文本，最大 1 MB。文件订阅是静态快照；更新请重新上传，不会自动获取流量变化。

校准流量

填写服务商面板的总量和剩余流量，保存为手动快照。连接检测不会自动扣减额度；后续需更新数值。

推送模式设置

订阅被 Cloudflare 验证页等拦截时，改由你自己电脑上的脚本去拉取，再推送到这里。订阅链接只保存在你的电脑上。

  1. 用 sub-push.ps1 脚本，按注释填入面板地址、ADMIN_TOKEN 和上面这一行（把链接换成你的订阅地址）。
  2. 右键脚本 → 使用 PowerShell 运行，先手动推送一次。
  3. 没问题后按 README 里的命令建一个每 30 分钟的计划任务。
